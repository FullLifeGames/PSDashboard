# The evaluation assumes perfect information, and set sensitivity widens the verdict instead

The engine scores a position as if both full sets were known: each field comes from the first source that knows it, in this order: what the replay revealed plus the user's edits, the pasted team and Open Team Sheets (the teams both players show before the game), fitted spreads, Smogon usage guesses, published sets (`ARCHITECTURE.md`, team precedence). A "revealed information only" mode is a non-goal of the first design (31.07.2026); the engine scores whatever position it receives, so such a mode would not need a rewrite. The roadmap of the same day gives the reason for the premise: set prediction mattered as much as search in the bot Foul Play (88 % GXE in randoms against 80 % in OU, from hidden-set uncertainty alone; GXE is a rating-based win-rate measure on Showdown's ladder), and the dashboard is a perfect-information tool, since the user can paste and import both sets. Published Smogon sets are read as published (user gate 06.10.2026: Grassy Glide beside Wood Hammer stays; a veto applies only to a contradictory pair such as Close Combat with Body Press), and protocol evidence rules a guess out before it survives (a disproven ability or item walks to the next candidate). The price is that guessed sets enter as facts: a wrong Choice-item guess fabricates move locks, and a verdict can grade a player for not knowing what the reconstruction pretends everyone knows. The calibration-honesty round (08.08.2026) kept the assumption and added a counter, decided with the user: a flagged verdict is re-evaluated with the opponent's alternative guessed items (`selectProbeCombos`: up to two involved Pokémon, two items each), the interval widens, one summary clause says so, and the verdict softens to the lowest-blame tier. No new UI element. A probe can only soften a verdict and never make it harsher. The same position serves the branch panel, the graph sweep and external engines, which receive the guessed teams in `state` and a note that the user can correct them (`ENGINES.md`).

## Considered options

- A hidden-information search (belief states: the opponent's sets as a probability distribution): the design of 08.08.2026 calls belief-averaged evaluation over sampled sets "the principled end state" and defers it "until sensitivity proves the demand". The sources record no cost or measurement.
- Dropping a correct rule because the bank reads it worse (AGENTS.md, "A rule that is right by the game stays"): rejected, see ADR 0006.

## Consequences

The race between the pasted sets and the worker's resolved sets can still change the probe list; it fired in no run of nine feedback runs, so the triage closed T27 as obsolete (a return gets a new number). Guessed fields carry `source: 'guessed'` with a probability; imported sets are `manual`.
